# Telegram-Sentinel

> 自架式 Telegram 安全管理平台

🚧 **目前狀態：** 開發中

## 專案介紹

Telegram-Sentinel 是一套自架式 Telegram 安全管理平台，提供多帳號管理、垃圾訊息偵測、OCR 圖片辨識、AI 分析、規則引擎及 Web 管理介面。

## 預計功能

- ✅ 多帳號管理
- ✅ 訊息監控
- ✅ 規則引擎（Rule Engine）
- ✅ OCR 圖片文字辨識
- ✅ AI 智慧分類（選用）
- ✅ 網址信譽檢查（Reputation）
- ✅ 外掛系統（Plugin）
- ✅ Web 管理介面
- ✅ Docker 一鍵部署
- ✅ ARM64／AMD64 支援
